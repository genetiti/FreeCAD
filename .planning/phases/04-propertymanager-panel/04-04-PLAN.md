**FLOW-01 is the R3-BLOCKER1 / R4-BLOCKER / R6-MAJOR1 correction.** The sketch-exit handler must NOT hang off the transient-teardown `FwRibbonContext`/`s_ribbonContext`. `FwWorkbench::deactivated()` calls `FwLayout::unmountRibbon()` (FwWorkbench.cpp:66/71) which does `s_ribbonContext.reset()` (FwLayout.cpp:280-286) SYNCHRONOUSLY, and a sketch edit transiently activates `SketcherWorkbench` (ViewProviderSketch.cpp:635/3963-3964) so `deactivated()` fires (Application.cpp:1984 before :2006) BEFORE `signalResetEdit` (Document.cpp:747-750) — so a FLOW-01 handler on the `s_ribbonContext` `signalResetEdit` consumer (FwRibbonContext.cpp:111-121) would be DESTROYED before sketch exit fires (the isolation test passes while the product fails).
