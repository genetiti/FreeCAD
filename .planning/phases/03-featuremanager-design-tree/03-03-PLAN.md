<objective>
Deliver the headline SolidWorks slice of this phase: a SolidWorks user grabs the rollback bar in the FeatureManager and drags it up the tree to roll the model back to an earlier feature state — features below the bar grey out, the 3D view shows the rolled-back result, and dragging the bar back down (or "Roll to End") restores forward. The bar drives the REAL `Body.Tip` (true suppress-below + recompute) through the existing `PartDesign_MoveTip` command-ID — fired under an RAII `FwSelectionGuard` (snapshot/clear/select-target/restore, because the command reads global `Gui::Selection`) and with NO outer FreeWorks transaction (the command opens its own) — with no module link. It snaps to solid features via a LINK-FREE resolver (Body `Group` + type-name string, never the C++-only `getPrevSolidFeature`/`isSolidFeature`), reuses the Python-only `Body.insertObject` for insert-at-bar with an explicit post-insert Tip policy, and holds NO new persisted state — `Tip` is the single source of truth (CONTEXT D-04/D-05/D-06, RESEARCH Spike B + Pitfalls 4/5; reviewer concerns 1/4/5/6/7).
