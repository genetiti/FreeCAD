<objective>
Deliver the headline SolidWorks slice of this phase: a SolidWorks user grabs the rollback bar in the FeatureManager and drags it up the tree to roll the model back to an earlier feature state — features below the bar grey out, the 3D view shows the rolled-back result, and dragging the bar back down (or "Roll to End") restores forward. The bar drives the REAL `Body.Tip` (true suppress-below + recompute) through the existing `PartDesign_MoveTip` command path with no module link, reuses `Body::insertObject` for insert-at-bar, and holds NO new persisted state — `Tip` is the single source of truth (CONTEXT D-04/D-05/D-06, RESEARCH Spike B + Pitfalls 4/5).

Purpose: This closes TREE-02 and completes the phase's core loop — after this plan a real user can roll back, insert mid-history, and restore, which they could not after Plan 03-02. SC5 (the daily-SW-user "feels like SW" acceptance) and the live 3D/drag-feel items are routed to `SPIKE_LIVE_CHECKLIST.md` because this environment has no build tree / live GUI (Phase 1/2 verification-deferral precedent) — recorded as open obligations, never fabricated.
