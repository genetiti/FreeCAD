## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer-authored map → CommandManager | Curated/spike command-ID strings are developer constants resolved via `getCommandByName` (null-checked, D-08). No user-supplied input parsed this phase. |
| FreeWorks Gui widget → App layer | Ribbon only reads command metadata/edit state via Gui getters/signals; never includes or mutates App. |
| fork code ↔ upstream shared files | Only additive `target_sources`/test-list edits; any unavoidable shared touch gets `// SW-FORK HOOK`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Repudiation/Legal | New source/test files, SPIKE.md | mitigate | No "SolidWorks" identifier/string in any new source file; `tools/fw-string-leak-grep.sh` CI gate; descriptive behavior comments only |
| T-02-02 | Tampering | tests/src/Gui/CMakeLists.txt, src/Gui/FreeWorks/CMakeLists.txt | mitigate | Additive `target_sources`/test-list edits only; no shared MainWindow/Gui edits; `// SW-FORK HOOK` if any unavoidable shared touch arises |
| T-02-03 | Info Disclosure | FwRibbon ↔ App separation | mitigate | No `App/` includes in FwRibbon; command firing via existing `Gui::Command`/`CommandManager` only |
| T-02-04 | Spoofing/Input Validation | Command-ID resolution | accept | IDs are developer-authored constants; `getCommandByName` null-checked (D-08 omit-missing); no user input — low risk |
| T-02-SC | Tampering/Supply chain | SARibbon (only if spike FAILS) | mitigate | Vendor-vet gate (UI-SPEC § Registry Safety): MIT confirm, pin v2.8.0, clear leak/provenance grep, vendored submodule not Pixi dep — blocking until cleared |
